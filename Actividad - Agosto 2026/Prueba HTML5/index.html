Estructura Web Básica

Este es un ejemplo de una estructura web básica utilizando HTML5.

Para empezar, ¿Qué es una estructura web básica en HTML?

Una estructura web básica en HTML5 consiste en una serie de elementos que definen la organización y el contenido de una página web. Los elementos más comunes incluyen:

  • <!DOCTYPE html>: Define el tipo de documento y la versión de HTML.
  • <html>: Elemento raíz que contiene todo el contenido de la página.
  • <head>: Contiene metadatos, enlaces a hojas de estilo, scripts y el título de la página.
  • <body>: Contiene el contenido visible de la página, como texto, imágenes y enlaces.

Además, dentro de estas etiquetas se pueden utilizar otros elementos para organizar mejor la información de la página web.

  • <h1>: Se utiliza para colocar el título principal de la página.
  • <p>: Se utiliza para escribir párrafos de texto.
  • <ul>: Crea una lista de elementos.
  • <li>: Representa cada elemento dentro de una lista.
  • <strong>: Sirve para resaltar un texto importante en negrita.

En este ejemplo también se utiliza CSS para cambiar la apariencia de la página, como el fondo, el tamaño y la posición de algunos elementos.

La imagen de fondo se coloca utilizando la propiedad background-image, mientras que background-size: cover permite que la imagen cubra toda la pantalla.

De esta manera, HTML5 permite crear la estructura de una página web de forma sencilla y organizada.
